# Link Tracker - сервис отслеживания изменений в ресурсах на GitHub и StackOverflow

Это pet-проект, который я реализовал в ходе обучения в Т-Академии
Проект представляет микросервисную архитектуру, состоящий из 3 слоев:

* **Bot Service** - управление пользователями и коммуникация через Telegram
* **Scrapper Service** - мониторинг контента и обнаружение изменений
* **AI Agent Service** - интеллектуальная обработка данных
