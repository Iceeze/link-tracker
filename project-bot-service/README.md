# LinkTracker — Telegram Bot Service

Микросервис Telegram-бота для интеллектуального агрегатора уведомлений **LinkTracker**.
Бот отвечает за взаимодействие с пользователем (прием команд, выдача ответов) и является частью модульной архитектуры проекта.

## 🛠 Стек технологий

* **Язык:** Python 3.12+
* **API** [FastAPI](https://fastapi.tiangolo.com/) (веб-фреймворк для создания API)
* **Telegram Bot:** [aiogram 3.x](https://docs.aiogram.dev/) (асинхронная работа с Telegram Bot API)
* **Конфигурация:** [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/) (типобезопасная валидация переменных окружения)
* **Логирование:** [structlog](https://www.structlog.org/) (структурное JSON-логирование)
* **Тестирование:** [pytest](https://docs.pytest.org/)
* **Менеджер зависимостей:** [Poetry](https://python-poetry.org/)

---

## 🚀 Инструкция по локальному запуску

### 1. Подготовка окружения

Убедитесь, что у вас установлены:

* Python версии 3.12 или выше.
* Менеджер пакетов poetry (инструкция по установке: [ссылка](https://python-poetry.org/docs/#installation)).

### 2. Установка зависимостей

Клонируйте репозиторий и установите все зависимости проекта, выполнив команду в корневой папке:

```bash
poetry install
```

### 3. Настройка конфигурации (.env)

Проект использует переменные окружения для защиты секретных данных.
В корне проекта (там же, где находится файл pyproject.toml) создайте файл с названием `.env`.

Добавьте в него токен вашего бота, полученный у [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

*Примечание: файл `.env` добавлен в .gitignore и не подлежит коммиту в систему контроля версий.*

### 4. Запуск приложения

Чтобы запустить бота, выполните следующую команду из корня проекта:

```bash
poetry run python -m src.main
```

---

## 🧪 Запуск автотестов

В проекте реализованы unit-тесты (с использованием моков), покрывающие позитивные и негативные сценарии обработки команд.

Для запуска тестов выполните команду:

```bash
poetry run pytest -v
```

Флаг -v (verbose) выведет подробный список всех пройденных сценариев.
